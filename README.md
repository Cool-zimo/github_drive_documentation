## ✨ 主要特性

- **文件管理**：上传、下载、删除、移动、重命名文件和文件夹
- **大文件支持**：自动分片，突破单仓库容量限制
- **多仓库存储**：自动创建并管理多个存储仓库
- **文件分享**：一键生成分享链接，自动启用 Pages
- **插件系统**：全屏运行的插件生态，支持游戏与工具
- **多账号管理**：支持多个 GitHub 账号切换
- **仓鼠联动**：与仓库管理面板共享登录状态
