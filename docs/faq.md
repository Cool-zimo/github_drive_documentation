# 常见问题

## 基础问题

### Token 安全吗？
Token 仅保存在浏览器 localStorage 中，不会上传到任何第三方服务器。所有 API 请求直接从浏览器发往 GitHub。

### 文件存在哪里？
文件以 base64 编码存储在 GitHub 仓库中。大文件（>10MB）自动分片，分散存储到多个仓库。

### 单文件最大支持多大？
单分片最大 50MB，理论上文件大小无上限（分片数量不限）。但受 GitHub API 速率限制，超大文件上传较慢。

### 为什么下载的文件损坏？
如果是 v20260827p 之前上传的文件，可能因为二进制编码 bug 导致损坏。请删除后重新上传。

## 分享问题

### 分享链接多久生效？
分享创建后，GitHub Pages 需要 1-3 分钟构建。应用会自动轮询 Pages 状态，就绪后提示。

### 如何删除分享？
侧边栏「🔗 我的分享」→ 找到分享 → 删除。这会删除整个分享仓库。

### 为什么我的分享没出现在「发现分享」？
- 旧版分享仓库名是 `share-xxx` 格式，不是标准的 `gd-share-` 格式
- 需要重新分享才会被搜索到
- 仓库必须是公开的

## 插件问题

### 插件安全吗？
插件在 iframe 沙箱中运行，只能通过有限的 API 与 Drive 交互。但插件可以获取你的 GitHub Token，请只安装可信来源的插件。

### 如何开发自己的插件？
参见 [插件开发指南](plugin-development.md)。

### 插件数据存在哪里？
插件 HTML 保存在浏览器 localStorage 中。清除浏览器数据会丢失已安装的插件，需要重新安装。

## 其他

### 仓库体积太大怎么办？
仓库已配置 GitHub Actions 每周自动压缩 Git 历史。也可手动触发：仓库 → Actions → 「清理仓库历史」→ Run workflow。

### 支持移动端吗？
支持响应式布局。移动端侧边栏可通过汉堡菜单展开，长按文件触发右键菜单。
