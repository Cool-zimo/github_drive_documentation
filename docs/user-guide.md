# 用户指南

## 文件管理

### 视图切换
工具栏 ▦/☰ 按钮切换网格视图和列表视图，偏好自动保存。

### 多选操作
- 按住 Ctrl/Cmd 点击文件，切换选中状态
- 选中多个文件后，右键任意一个可批量：删除、移动、复制、收藏、下载、分享

### 拖拽移动
- 拖拽文件到当前目录的文件夹上，移动到该文件夹
- 拖拽文件到顶部面包屑的任意一级，移动到对应目录
- 拖拽到「Drive Home」移到根目录

### 路径导航
- 顶部面包屑显示当前路径，点击任意一级跳转
- 路径过长时可横向滚动

## 收藏与最近使用
- 右键文件 → 收藏/取消收藏
- 侧边栏「⭐ 收藏」查看所有收藏（含文件夹）
- 侧边栏「🕐 最近使用」查看最近打开的文件

## 分享

### 创建分享
1. 右键文件（可多选）→ 分享
2. 填写名称和描述
3. 自动创建格式为 `gd-share-{名称}-{时间戳}` 的公开仓库
4. 启用 GitHub Pages，生成分享链接

### 发现分享
- 侧边栏「🌐 发现分享」
- 自动搜索所有 `gd-share-` 开头的公开仓库
- 验证标准分享格式（share.json）
- 卡片显示作者、简介、文件数，一键跳转

## 插件

### 安装插件
1. 侧边栏「🧩 插件广场」
2. 浏览可用插件
3. 点击「⬇️ 安装」
4. 点击「▶️ 运行」使用

### 管理插件
- 已安装的插件显示「已安装」标签
- 点击「🗑️ 卸载」移除
- 插件 HTML 保存在浏览器 localStorage

## 设置与维护

### 清理仓库历史
大文件反复修改会导致 Git 仓库体积膨胀。仓库已配置 GitHub Actions，每周日自动压缩历史。也可手动触发：
仓库 → Actions → 「清理仓库历史」→ Run workflow

### 退出登录
侧边栏底部「退出登录」，清除本地 Token 和所有数据。
